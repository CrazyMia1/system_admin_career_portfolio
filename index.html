01 CAREER ROADMAP

From first-line support
to systems expert.

Career growth often comes through hands-on experience, continuous learning, and taking on more complex systems. Explore three common stages below.

LEVEL 01 · ENTRY01
⌁

IT Support Technician

The first point of contact for users who need technical help.

Main responsibilities

  • Diagnose hardware and software issues
  • Install applications and configure devices
  • Help users with accounts and access
  • Record issues and solutions in tickets

Skills and experience

Windows basicsCommunicationTroubleshooting

System Administrator

Keeps servers, operating systems, accounts, and services reliable.

Main responsibilities

  • Manage servers and user permissions
  • Monitor system health and performance
  • Maintain backups and recovery plans
  • Apply updates and security controls

Skills and experience

Linux / Windows ServerNetworkingScripting

03 JOB ROLES

Different roles, different focus.

These roles work together, but they focus on different levels of technical support, system ownership, and infrastructure design.

Job role Main focus Typical tasks Scope
IT Support Technician User support Fix device issues, install software, answer support requests. User-facing
System Administrator Daily system operations Manage servers, accounts, backups, updates, and monitoring. System-wide
Systems Engineer Design and improvement Build infrastructure solutions, automate work, plan upgrades. Infrastructure
IT Infrastructure Manager People and services Set priorities, manage resources, coordinate projects and service reliability. Strategic
